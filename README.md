# EINUNDZWANZIG POOL 🌋

Eine Fokus-Plattform für Bitcoin-Marktanalysen, interaktive Indikatoren und nützliche Einsteiger-Ressourcen.

---

## 🚀 Features

- **Bitcoin-Marktanalysen & Metriken**: Interaktive Daten-Visualisierungen und Diagramme wichtiger On-Chain- und Preis-Indikatoren.
- **Einsteiger-Ressourcen**: Kuratierte Guides, Definitionen und Lernmaterialien für den optimalen Einstieg.
- **Echtzeit-News**: Ein eingebautes News-Dashboard mit RSS-Feeds der wichtigsten deutschsprachigen Bitcoin-Medien.
